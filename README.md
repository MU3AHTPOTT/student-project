ПРОГРАММА РАСЧЕТА СТОИМОСТИ БИЛЕТОВ



ОПИСАНИЕ



Консольная программа для расчета стоимости билетов для взрослых и детей с учетом скидок.



ВОЗМОЖНОСТИ



- Вывод таблицы стоимости для двух взрослых и от 1 до 5 детей.

- Ввод количества взрослых и детей.

- Проверка корректности введенных данных.

- Расчет общей стоимости билетов.

- Применение скидок в зависимости от количества билетов.

- Вывод чека с подробной информацией о заказе.

- Повторный расчет заказа.



СТОИМОСТЬ БИЛЕТОВ



- Взрослый билет - 2000 тенге.

- Детский билет - 1000 тенге.



УСЛОВИЯ СКИДОК



- Менее 4 билетов - 0%.

- От 4 до 6 билетов включительно - 5%.

- От 7 билетов - 10%.



ЗАПУСК



Для запуска программы необходим Python 3.12 или новее.



Выполните команду в терминале:



```bash

python main.py

```
